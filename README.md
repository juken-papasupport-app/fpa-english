# FP&A English

FP&A（医療機器の外資系）の実務でよく使う英語表現を、**長い文でも途切れずに正確に話せる**ようにするための訓練アプリ（iPhone向けPWA）。

## 訓練メニュー
1. 表現カード（9場面×12表現、音声付き、間隔反復）
2. 和→英で話す（音声認識 → 模範文との差分を色分け、使うべき表現のチェック）
3. 文を伸ばす（短い文に節を足して長い1文にする、4段階）
4. シャドーイング・音読（文ごとの読み上げ、録音して聞き比べ、流暢さの計測）
5. 1分スピーチ＋流暢さメーター（話した長さ・1秒以上の沈黙・最長の沈黙・1分あたりの語数）
6. 会議ロールプレイ（相手のせりふを読み上げ → 自分の言葉で回答 → 回答例と比較）
- 🎯 弱点集中モード：まちがえた表現・長い文と、Claudeの添削結果（JSONで取り込み）だけを練習
- Claudeへの添削依頼・音声ロールプレイ用の指示文を自動作成
- 声を出せないモード、記録・推移、バックアップ

## ファイル
- `content/phrases.js` … 場面と表現カード
- `content/drills.js` … 文を伸ばす練習・シャドーイング文・1分スピーチ・ロールプレイ
- `audio.js` … 読み上げ・音声認識・録音と沈黙の計測・差分比較
- `app.js` / `style.css` / `index.html` … アプリ本体

学習記録・発話・添削は端末の中（localStorage）だけに保存し、このリポジトリには置かない。
内容の追加は各配列の末尾へ（学習記録は順番で結びつくため）。
